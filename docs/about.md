# About

The Digitizer board was designed by INFN-NA and INFN-RM.

The Digitizer FW is implemented by INFN-NA, INFN-RM, and INFN-PI.

The Digitizer SW running on the soft microcontroller embedded in the FPGA, the so-called _Microblaze_, was developed by Fabrizio Ameli.

For more information about this documentation or to request more explanation or to contribute, please write to <fabrizio.ameli@roma1.infn.it>
