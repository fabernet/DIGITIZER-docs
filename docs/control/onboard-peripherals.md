# On board peripherals

## EEPROM

A 2-Kbit I2C serial EEPROM from Microchip, with part number 24AA02E48T, is onboard. This device has a double function: storing few bytes available to the user and implementing EUI-48 and EUI-64 globally unique node address stored in the upper-half of the array and permanently write-protected.

Both unique codes start with a 24-bit code called __OUI__ (Organizationally Unique Identifier) which is assigned to Microchip by the IEEE Registration Authority. The EUI-48 features 3 more bytes, called Extension Identifier, and are generated by Microchip to guarantee a unique 48-bit value. The EUI-64 has 8 bytes: the OUI is in the first 3 bytes, while the remaining 5 bytes are the Extension Identifier and are generated by Microchip to ensure a globally unique, 64-bit value.

These 2 codes can be used to univocally identify each Digitizer board linking this values with the data matrix and the board Serial Number printed on the PCB.

More information on the specific device can be found on the Microchhip website at [this page](https://www.microchip.com/en-us/product/24aa02e48).

### EEPROM SC Commands

The slow control command which enable front-end is the following:
```
READ DIGx OUI
READ DIGx EID
```
where:

- `x` is the digitizer number (0/1)

## RFID

Since the very first release of the Digitizer, DIGv2, an RFID device has been available on board. The chosen device is the `Murata LXMS21ACMF-218`, which can be read by a dedicated RFID reader.

Due to the lack of availability of Murata RFID components at the time of production, the IC will not be mounted and will be replaced by a data matrix code printed on the PCB (top and bottom layers with different codes).
