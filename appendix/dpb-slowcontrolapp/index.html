Linux dpb-slowcontrolapp service#

This is the target slow control communication path with the Digitizer; it is implemented by the DPB with a service, called dpb-slowcontrolapp, which manages the interface to the digitizer. Details of this implementation can be found here.

The commands are exposed by a Linux service implemented in the DPB board that sits on top of the protocol above (DIG0 / DIG1). Each service command maps to one or more HKDIG_* write commands from the tables above.

dpb-slowcontrolapp commands consist if a READ/SET command, followed by Digitizer selection DIG0/DIG1 and then by the Service command shown hereafter. The following table maps the write commands of the two protocols:

HKDIG_SET_IT_NUM / HKDIG_SET_IT_ALL sitn / sita INTTIME 0–17, ALL number
HKDIG_SET_CAL_N scale CALIBEN 0–17 ON/OFF
HKDIG_SET_CAL_TYPE scalm CALIBTYPE – 0–3
HKDIG_SET_CAL_PERIOD scalt CALIBPER – number
HKDIG_SET_CAL_GAIN scalg CALIBGAIN – LOW/HIGH
HKDIG_SET_CAL_POWER scalp CALIBPWR – 0–1
HKDIG_SET_CAL_PLS_LEN scall CALIBLEN – number
HKDIG_SET_CAL_PLS_AMP scala CALIBAMP – number
HKDIG_SET_CAL_NPDN scaltp CALIBPDN – number

Note: STATUS (write) is a somewhat misleading name — it actually writes the channel control register (HKDIG_SET_CHN_CNTRL), not a status register. See STATUS (read) below, which does read the actual status register.
