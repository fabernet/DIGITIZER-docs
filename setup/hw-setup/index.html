HW setup#

Starting from DIGv5, the Analog 5 volts power rail is set by a DAC, the MCP4725A0T-E/CH. This DAC has a EEPROM which contains the value loaded at power up. This default value will be programmed during the production to the desired value.

Since DIGv5, the 5V power rail provided to the OD has a separate source.

Slow control command#

The slow control command which sets the 5VA is the following:

SET DIGx SET5VA val

where:

  • x is the digitizer number (0/1)
  • val is the 5VA DAC value ranging from 0 to 4095.
